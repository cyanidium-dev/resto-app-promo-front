# MySaniTrace — сайт

Маркетинговый сайт для платформы цифрового HACCP и операционного контроля в HoReCa.
5 страниц, 3 языка (RO основной, EN, RU), светлая и тёмная тема.

- [Техническое задание и чеклист](docs/TZ.md)
- [Бриф на генерацию изображений](docs/IMAGE-BRIEF.md)

## Запуск

```bash
npm install
```

```bash
npm run dev
```

Открыть http://localhost:3000

## Языки и маршруты

RO живёт в корне без префикса — это основной рынок. EN и RU с префиксом. Пути локализованы.

| Внутренний путь | RO | EN | RU |
|---|---|---|---|
| `/` | `/` | `/en` | `/ru` |
| `/platform` | `/platforma` | `/en/platform` | `/ru/platforma` |
| `/solutions` | `/solutii` | `/en/solutions` | `/ru/resheniya` |
| `/pricing` | `/preturi` | `/en/pricing` | `/ru/tseny` |
| `/contact` | `/contact` | `/en/contact` | `/ru/kontakty` |

Тексты — в `messages/{ro,en,ru}.json`. Маршруты — в `src/i18n/routing.ts`; `hreflang` и `sitemap.xml` собираются из этой же таблицы, поэтому разъехаться не могут.

## Изображения

Все визуалы продукта — сменные слоты. Пути собраны в `src/config/site.ts`.

Пока файла нет, слот показывает заглушку с именем ожидаемого файла и держит пропорции — вёрстка не поедет, когда картинки появятся. Достаточно положить их в `public/images/` по путям из конфига, лишний код трогать не нужно.

Промпты и точные имена файлов — в [docs/IMAGE-BRIEF.md](docs/IMAGE-BRIEF.md).

## Форма заявки

`POST /api/lead` → надёжное сохранение → письмо в продажи (Resend) + строка в Google Таблице → автоответ заявителю на его языке → редирект на страницу «спасибо».

Переменные окружения — в [.env.example](.env.example).

Без настроенных провайдеров форма всё равно работает в разработке: заявки пишутся в `.leads/leads.jsonl`. В продакшене API откажется принять заявку, которую не может доставить, вместо того чтобы показать ложный успех.
